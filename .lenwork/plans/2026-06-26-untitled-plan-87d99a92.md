That behavior (“show code **only when** the image fails”) is exactly what the HTML `alt` attribute is for:

- If the SVG loads → browser shows the image, **not** the alt text.
- If it fails → browser shows the broken-image icon and the **alt text** (your team code).

So conceptually: **yes, your requirement is already the normal browser behavior**.
