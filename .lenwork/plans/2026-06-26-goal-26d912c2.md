Plan for the match component formatting tweaks (no changes executed yet):

## Goal
Make **bet display** and **actual score display** use **mirrored formatting**:
- DIP shown *as part of the bet*, directly under the bet score, same style but slightly smaller.
- Don’t show literal `"DIP:"`.
- Change duration DIP values:
  - `"90"` → **`"w 90 minut"`**
  - `"120"` → **`"po dogrywce"`**
- For **actual score display**:
  - keep the score formatting (the `( … )` line) but:
    - don’t show penalty score (`6:5`) anymore
    - don’t show `"po karnych"` (redundant)
    - do show `"po dogrywce"` when duration is `EXTRA_TIME`
    - when match decided by penalties, show only the **outcome** aligned with DIP-style (i.e., “karne: XXX”), not the penalty numbers

## Files involved
- `app/utils/components.py` (the `render_match_row()` component and helper functions)

## Steps
1) **Read current component implementation**
   - Verify where bet score is rendered (center column) and where we currently show DIP and actual score line.

2) **Implement display-normalization helpers**
   - Add a helper to map stored dip values to display strings:
     - `"90"` → `"w 90 minut"`
     - `"120"` → `"po dogrywce"`
     - `"karne: XXX"` → `"karne: XXX"` (unchanged, but without “DIP:” label)
   - Add helper to compute “actual match context label” (mirroring DIP concepts):
     - If `duration == EXTRA_TIME` → `"po dogrywce"`
     - If `duration == PENALTY_SHOOTOUT` → `"karne: {winner_code}"` (derived from `pens_*` + home/away_code)
     - Else → none

3) **Update bet rendering (view mode)**
   - Under the bet score (`home_bet : away_bet`), render a smaller/grey line with the formatted DIP value (if knockout and dip present).
   - No `DIP:` prefix.

4) **Update actual score rendering**
   - Keep `(flt_home : flt_away)` but append, in the same small grey style, the context label:
     - `po dogrywce` for ET
     - `karne: XXX` for penalties (no penalty numbers)
   - Remove `"po karnych"` and remove penalty score from display entirely.

5) **Quick verification**
   - Run `python -m compileall -q .`
   - Run a small DEMO_MODE snippet to ensure `render_match_row()` receives required fields and winner resolution works without crashing.

## Expected outcome
- In report view, each knockout bet shows:
  - the bet score
  - directly underneath: `w 90 minut` / `po dogrywce` / `karne: XXX` (small font)
- The actual score line shows:
  - `(X : Y)` plus either `po dogrywce` or `karne: XXX` (mirrored semantics), without penalty score numbers.
